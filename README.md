# Android Auto ヘッドユニット エミュレーター

USB でつないだスマホの Android Auto を、PC 上の「車載ナビ画面」に映すための Windows 用ランチャーです。
画面表示とプロトコル処理には Google 公式の **Desktop Head Unit (DHU)** を使い、このアプリはその準備・起動・車両操作を GUI で行います。

## 起動

```
run.bat
```

（Python 3.10 以降。標準ライブラリだけで動くので、追加インストールは不要です）

## 使い方

1. **必要なツール** — 「ダウンロードしてインストール」を押すと、Google の SDK リポジトリから
   `platform-tools`（adb）と `Desktop Head Unit` を取得し、`%LOCALAPPDATA%\Android\Sdk` に入れます
   （Android Studio と同じ場所。Android SDK ライセンスへの同意が必要です）。
2. **スマホ** — USB で接続し、接続方式を選びます。
   - **USB アクセサリーモード**（既定）: 実車と同じ AOA 方式。ヘッドユニットサーバーや adb のポート転送は使いません。
     Windows では、切り替わった後の USB デバイス（Android Accessory Interface）に WinUSB ドライバーの割り当てが必要です（アプリが検出して手順を案内します）。
     停止・再起動のときは、adb でスマホの USB をつなぎ直させてアクセサリーモードを解除します（ケーブルの抜き差しの代わり。USB デバッグの許可が必要）。
   - **ADB 経由**: Android Auto の開発者モードで「ヘッドユニット サーバーを起動」し、adb でポート転送してつなぐ方式。確実に動きます。
3. **ナビ画面の設定** — 画面サイズ（800×480〜1920×1080、ワイド）、DPI、操作方式（タッチ／ロータリー／ハイブリッド）など。
4. **▶ 起動** — DHU のウィンドウにナビ画面が表示されます。

起動中は右側のパネルから次の操作ができます。

- ステアリングスイッチ（ホーム、戻る、ナビ、電話、メディア、音声、曲送り、発信・終話）とロータリーコマンダー
- 昼／夜モード、シフト（P/R/N/D）、パーキングブレーキ、車速、燃料
- GPS 走行シミュレーション（皇居周回ルートを指定速度で走行）と、走行中の操作制限
- 録音済み音声コマンドの再生、スクリーンショット（`Pictures\AAHeadUnit`）、DHU コマンドの直接入力

設定は `%APPDATA%\AAHeadUnitEmu\` に保存されます。

## ファイル

| ファイル | 内容 |
|---|---|
| `headunit.py` | GUI 本体（DHU プロセス管理、adb 操作、車両シミュレーション） |
| `sdk.py` | SDK の検出と、Google リポジトリからのダウンロード・検証・展開 |
| `run.bat` | 起動用 |
